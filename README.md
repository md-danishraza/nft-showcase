# NFT UI Showcase

A modern, animated NFT marketplace UI built with React, Tailwind CSS, and Framer Motion.

## Live Demo

🔗 [View Live Site](https://nft-ui-showcase.netlify.app/)

## Tech Stack

- React 18
- Tailwind CSS
- Vite
- Custom animations

## Components

- Responsive Navbar with mobile menu
- Hero Section with animated blobs
- Trending NFTs grid
- Bitcoin Art section
- Community CTA
- About Us page (Hero, Story, Mission/Vision, Team, Stats)
- Glassmorphic Footer

## Setup

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build
```
